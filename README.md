# ASEATI

Sitio web informativo de la **Asociación de Estudiantes de Administración de Tecnología de Información** (ASEATI) del Tecnológico de Costa Rica.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

El sitio se publica en Vercel a partir del build de Vite (`dist`).

- Producción: https://aseati.vercel.app
- Repositorio: https://github.com/avegacr/ASEATI
